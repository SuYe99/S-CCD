⚠️ **Warning**

`S-CCD` is **no longer maintained**.

We have merged it and developed a new modern python package `pyxccd <https://github.com/Remote-Sensing-of-Land-Resource-Lab/pyxccd>`_.

To use the package, you simply installed it using pip:

.. code:: console

   pip install pyxccd

Note: it only supports windows and linux system so far. Please contact Su Ye (remotesensingsuy@gmail.com) if you wish to install it in the macOS system.
